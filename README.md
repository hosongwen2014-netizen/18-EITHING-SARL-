# 18 EITHING SARL - Site Web Vitrine

Site vitrine moderne, responsive et professionnel de **18 EITHING SARL**, entreprise spécialisée dans le Conseil, la Logistique de santé, l'Accompagnement psychologique et le Commerce général.

Domaine officiel : **[18eithing.bj](https://18eithing.bj)**

---

## 🚀 Structure du projet

- `index.html` : Structure HTML5 du site (Accueil, À propos, Services, Stats, Contact).
- `style.css` : Feuilles de style CSS3 modernes (Flexbox, Grid, Variables CSS, Animations, Responsive Design).
- `script.js` : Interactions JavaScript (Navigation mobile, animations au défilement scroll-reveal, navigation active).
- `logo.svg` : Logo vectoriel SVG de la marque 18 EITHING SARL.
- `CNAME` : Fichier de configuration du domaine personnalisé (`18eithing.bj`).
- `DOMAINE_ET_DNS.md` : Guide étape par étape pour la configuration DNS et la liaison du nom de domaine `18eithing.bj`.
